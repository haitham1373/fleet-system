# نظام إدارة الأسطول — شركة بروج العالم للنقل

نظام ويب متكامل لإدارة المركبات والصيانة والبطاريات والفحص الدوري والعقود
والمواقف، مبني بـ **Streamlit** و**SQLite**، وواجهة عربية كاملة باتجاه RTL.

## المزايا الرئيسية

- **لوحة تحكم** بمؤشرات الأسطول والتنبيهات التشغيلية والرسوم البيانية.
- **إدارة المركبات** بجدول عربي ملوّن حسب حالة الصيانة مع أعمدة العداد وتاريخ آخر صيانة، وبطاقة تنبيهات ذكية تعرض المركبات التي تحتاج صيانة خلال 30 يوماً.
- **سجلات الصيانة والفواتير** مع المرفقات وحالة السداد والتصفية والتصدير.
- **البطاريات والضمان** مع حساب تاريخ الانتهاء تلقائياً وتنبيهات الضمان.
- **الفحص الدوري** مع تقارير الفحص وتواريخ الصلاحية.
- **الفنادق والعقود** وإدارة دليل الفنادق والمحطات.
- **المواقف الذكية** من فواتير وعقود وفواتير شهرية.
- **التقرير الشامل** مع تصدير CSV وتنزيل مباشر بصيغة PDF جاهزة للطباعة.
- **بيان الركاب** لتجهيز كشف الرحلة وتنزيله بصيغة PDF دون حفظه في قاعدة البيانات.
- **إدارة المستخدمين والصلاحيات** و**النسخ الاحتياطي والاستعادة**.
- **سجل تدقيق** لجميع عمليات الإضافة والتعديل والحذف والدخول.

## المتطلبات

- Python 3.10 أو أحدث.
- الحزم المذكورة في `requirements.txt`:

```bash
pip install -r requirements.txt
```

## التشغيل

من داخل مجلد المشروع:

```bash
python -m streamlit run app.py
```

أو على Windows بالنقر المزدوج على `RunAPP.bat`، وللتشغيل الصامت استخدم
`run_silent.vbs`.

## أول تسجيل دخول

- عند إنشاء قاعدة بيانات جديدة يُنشأ حساب مدير باسم `admin`.
- كلمة المرور الافتراضية: `1234`، ويمكن تغييرها مباشرة من الشريط الجانبي.
- يمكن تحديد كلمة مرور أولية مختلفة قبل أول تشغيل عبر متغير البيئة
  `FLEET_ADMIN_PASSWORD`.

> يُنصح بتغيير كلمة المرور الافتراضية فور أول دخول.

## متغيرات البيئة الاختيارية

| المتغير | الافتراضي | الوصف |
| --- | --- | --- |
| `FLEET_DB_PATH` | `fleet.db` | مسار قاعدة البيانات |
| `FLEET_ADMIN_PASSWORD` | `1234` | كلمة مرور المدير عند أول تهيئة |
| `FLEET_SESSION_HOURS` | `8` | مدة انتهاء الجلسة بالساعات |
| `FLEET_MAX_UPLOAD_MB` | `10` | الحد الأقصى لحجم الملف المرفوع |
| `FLEET_PBKDF2_ITERATIONS` | `240000` | عدد تكرارات تشفير كلمة المرور |

## البيانات والنسخ الاحتياطي

- تُنشأ الجداول وتُرحّل البيانات القديمة تلقائياً عند بدء التشغيل، دون حذف
  البيانات الحالية.
- تُخزّن المرفقات داخل مجلدات مخصصة مثل `uploaded_invoices` و
  `battery_warranties` و`inspection_reports`.
- يمكن للمدير إنشاء نسخة احتياطية وتنزيلها أو استعادة نسخة من صفحة
  **النسخ الاحتياطي**.
- قبل أي استعادة يتم التحقق من سلامة ملف قاعدة البيانات (`integrity_check`)
  ومن وجود الجداول الأساسية، ثم تُنشأ نسخة أمان تلقائية. تُغلق جميع اتصالات
  قاعدة البيانات وتُنفّذ نقاط استرجاع WAL قبل الاستبدال وبعده لضمان استبدال
  كامل للبيانات، ويُطلب تسجيل الدخول من جديد بعد نجاح الاستعادة.

## ملاحظات أمنية

- كلمات المرور مشفرة باستخدام PBKDF2-HMAC-SHA256.
- جميع استعلامات قاعدة البيانات معاملاتية (Parameterized).
- الملفات المرفوعة تُفحص من حيث الامتداد والحجم قبل الحفظ.
- الجلسة تنتهي تلقائياً بعد مدة عدم النشاط المحددة.
- جميع العمليات الحساسة تُسجل في جدول `AuditLog`.
